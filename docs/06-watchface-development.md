# 06. 小米手环 9 / 9 Pro 表盘开发与制作全景指南

> 本章系统梳理小米手环 9 系列的表盘运作架构、开源工具链（EasyFace / Mi-Create）、切片规范、AOD 息屏设计红线以及表盘联动快应用的进阶技巧。

---

## 一、 表盘工作机制与文件构成

不同于以 JavaScript 逻辑驱动的快应用（QuickApp），小米手环的系统原生表盘直接由 **Xiaomi Vela 底层图形渲染引擎（Surface Pipeline）** 栅格化绘制，具有毫瓦级超低功耗特性。

### 1. 表盘归档解构
手环 9 / 9 Pro 的自定义表盘文件通常以 `.bin` 或 `.face` 形式分发，其解包后的内部核心包含三部分：
1. **元数据描述文件（`info.json` 或 XML）**：
   - 定义表盘作者、版本、支持的分辨率以及目标机型代号。
2. **图层排版配置文件**：
   - 描述所有可视控件的层级（Z-Index）、物理锚点坐标 `(x, y)`、对齐方式以及对应绑定的手环传感器数据源。
3. **位图图集资源（Sprites / Atlas）**：
   - 静态背景图、0~9 的数字字体切片、星期/月份切片、进度条弧线切片、电量/蓝牙状态图标等。

```
┌────────────────────────────────────────────────────────┐
│             小米手环 9 / 9 Pro 表盘工程包                │
│  ├── info.json (设备型号 / 屏幕宽高 / 权限元数据)          │
│  ├── layout.xml / watchface.json (数据绑定与坐标锚点)     │
│  │   ├── 时间组件 (时/分/秒/AM_PM 切片索引)             │
│  │   ├── 健康组件 (步数/心率/卡路里/PAI 数据流绑定)       │
│  │   └── 点击热区 (Hotspot -> 唤起指定快应用包名)        │
│  ├── images/ (PNG 切片图集: 背景、数字 0-9、图标)        │
│  └── aod/ (低功耗息屏图集: 极简时钟、微光元素)           │
└────────────────────────────────────────────────────────┘
```

| :--- | :--- | :--- | :--- |

## 三、 表盘切片与视觉规范

### 1. 物理分辨率与排版基准
- **小米手环 9 Pro**：
  - 物理基准：`336 × 480`。
  - 特性：四周为 2.5D 微曲面，推荐主要内容区保留左右各 `14px` 安全边距（可用有效宽 `308px`），适宜布局类似小手表的丰富多卡片信息。
- **小米手环 9 标准版**：
  - 物理基准：`192 × 490`。
  - 特性：细长跑道屏，上下两端为大半圆弧形，文字与数字必须居中沿纵向轴线紧凑排布，顶部/底部至少留出 `24px` 避开圆角裁切。

### 2. 切图资产准备要领
1. **纯黑底色铁律**：除特殊艺术表盘外，背景底图尽量使用全黑 `#000000`，彻底关闭 AMOLED 像素点，降低待机功耗。
2. **切片尺寸规整**：数字 0~9 切片高度建议完全一致，且每张切片紧贴文字轮廓裁剪（去除多余透明留白），以便于排版引擎准确计算字符间距。
3. **格式约束**：所有切片必须保存为透明背景 PNG（建议采用 TinyPNG 压缩以控制表盘总包体积在 2MB 以内）。

## 四、 AOD (Always-On Display) 息屏微光设计红线

AOD 息屏常亮是手环表盘最容易踩坑的环节。手环固件内置了严格的功耗与防烧屏监控（Watchdog）：

### 1. OPR（像素点亮率）红线：严格控制在 10% 以内
- **公式**：$\text{OPR} = \frac{\text{非纯黑点亮像素数}}{\text{屏幕总像素数}} \times 100\%$。
- **系统惩罚**：如果 AOD 层的发光像素面积超过 10%~15%，手环固件会强制判定为“非法功耗表盘”，**直接降级为系统默认数字时钟或彻底熄灭屏幕**。

### 2. 避免固定位置长久高亮（Anti-Burn-In）
- 即使亮度较低，固定的高对比白色发光点长达数周显示也会导致 AMOLED 局部老化衰减。
- 优秀的表盘引擎通常在整点或周期性触发 1~2 像素的微小位移（Pixel Shift）以保护屏幕。

### 3. AOD 刷新率限制
- 手环进入 AOD 模式后，屏幕刷新率会骤降至 1Hz（每分钟刷新一次），切勿在 AOD 图层中放置秒针、毫秒计数或复杂循环动效。

## 五、 进阶技巧：表盘点击热区唤醒快应用 (Hotspot)

手环 9 / 9 Pro 支持在表盘上设置交互热区（Hotspot），当用户轻触表盘上的某个小部件（如便签图标、日程区域、计算器图标）时，无需翻找繁琐的应用列表，即可瞬间无缝唤起独立开发的快应用！

### 配置范例（以唤醒腕上记事本为例）：
在表盘的交互配置段中添加：
```json
{
  "type": "hotspot",
  "name": "notepad_launcher",
  "rect": {
    "x": 20,
    "y": 320,
    "w": 80,
    "h": 80
  },
  "action": {
    "type": "launch_app",
    "package": "com.xiaomi.band.notepad",
    "target": "pages/index"
  }
}
```

- **`rect`**：在表盘画布上定义的矩形触控有效区域。
- **`package`**：对应快应用 `manifest.json` 中声明的唯一包名。
- **联动体验**：表盘负责毫瓦级低功耗常驻展示关键数据，快应用负责承接打字、编辑、复杂网络请求与交互，形成完美的穿戴工程闭环！

## 六、 表盘打包与真机部署流程

1. **在 EasyFace 或 Mi-Create 中导出表盘包**：
   导出为目标机型（如 `Mi Band 9 Pro`）对应的 `.face` 或 `.bin` 格式。
2. **切断官方 App 占用**：
   手机后台强制停止“小米运动健康”。
3. **使用 AstroBox 无线推送**：
   - 打开 AstroBox 并通过 AuthKey 建立蓝牙配对。
   - 在“表盘管理”或“自定义安装”模块选择本地 `.face` 文件。
   - 点击“同步表盘”，等待进度走完（1~2MB 文件通常需要 10~20 秒）。
4. **应用并生效**：
   手环长按主屏幕进入表盘选择列表，即可看到新表盘并直接滑动选用。
