# 03. 穿戴式 UI 设计、触控热区、AMOLED 节能与震动反馈规范

> 本章总结在小米手环 336×480 微型曲面屏上的交互设计规范与视觉工程原则，帮助开发者打造丝滑、防误触且省电的优秀穿戴作品。

---

## 一、微曲面物理安全区与边距法则

手环 9 Pro / 8 Pro 采用 2.5D 微曲面盖板玻璃，四周存在物理弧度边缘与切角。

```
0px ─────────────────── 336px ───► X
 │  ┌──────────────────────┐
 │  │ ⚠️ 顶部边缘安全内边距 │  (高度 ≥ 10px，避开曲面畸变)
 │  │ ┌──────────────────┐ │
 │  │ │                  │ │
 │  │ │  有效交互内容区  │ │
 │  │ │  (宽度约 308px)  │ │
 │  │ │                  │ │
 │  │ └──────────────────┘ │
 │  │ ⚠️ 底部边缘安全内边距 │  (高度 ≥ 12px，避开手势滑动区)
 │  └──────────────────────┘
 ▼
 Y (480px)
```

### 1. 核心安全边距规范：
- **左右水平内边距**：
  - 外层容器必须设置 `padding: 0 14px;`。
  - 内部可用最大内容宽度为 **`308px`**（`336 - 14 * 2 = 308`）。
  - 所有按钮、卡片、输入框宽度建议基于 `308px` 进行栅格化划分。
- **垂直边缘内边距**：
  - 顶部距屏顶预留 `≥ 10px`，防止内容被上盖板圆角裁切。
  - 底部距屏底预留 `≥ 12px`，防止从底部边缘上滑时与手环系统的控制中心或通知栏手势冲突。

## 二、触控热区底线与防误触工程

在 1.74 英寸的小屏幕上，成年人拇指的触控接触面通常达到 40~50px 以上。

| 组件类型 | 最小物理高度 | 推荐按键宽度 | 最小间隙 (Margin/Gap) | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **主功能操作键** (如新建、打字) | **44px ~ 48px** | 308px (全宽居中) | 6px | 拇指盲按命中率 100% |
| **小键盘输入键** (如九键按键) | **48px ~ 53px** | 97px ~ 100px (三列) | 4px | 保持九宫格工整且大字防误触 |
| **控制栏功能键** (如翻页、光标) | **46px** | 42px ~ 52px (横排 5~6 键) | 2px ~ 4px | 必须紧凑但绝不粘连 |
| **列表卡片项** (如便签条目) | **60px ~ 72px** | 308px | 8px | 预留左右删除与点击展开空间 |

### 防误触设计铁律：
1. **禁止过密排列**：两个功能截然相反的按键（如“删除”与“确认”），间距必须 $\ge 6\text{px}$，或使用高对比度底色区分。
2. **边缘扩大点击热区**：视觉上是小图标（如全屏展开图标 `⤢`），外层包裹的 `<div>` 必须设置至少 `28px × 32px` 并带有 `justify-content: center; align-items: center`。

## 三、AMOLED 极低能耗色彩体系

AMOLED 屏幕每个像素独立自发光，纯黑像素几乎不消耗电量。

```
纯白全屏显示：耗电极高 (可达 100~150mA)，加速发热
纯黑底色 + 高对比重点配色：耗电仅需 15~25mA，续航延长数倍！
```

### 推荐设计调色板：

| 角色 | 色值代码 | 视觉效果 | 适用元素 |
| :--- | :--- | :--- | :--- |
| **深邃底色 (Background)** | `#000000` | 纯黑 (Pixel Off) | 根容器 `.root`、全屏背景 |
| **一级卡片 (Surface 1)** | `#1c1c1e` | 极暗微灰 | 便签卡片、输入大文本框 |
| **二级功能区 (Surface 2)** | `#27272a` | 中暗灰 | 键盘按键、光标控制按钮 |
| **三级辅助区 (Surface 3)** | `#38383c` | 亮暗灰 | 退格键、空格键、次要功能键 |
| **主点睛色 (Accent)** | `#ff9500` | 活力橙 | 激活状态音节、新建按钮、确定按钮 |
| **一级文字 (Text Primary)** | `#ffffff` | 纯白高对比 | 核心标题、候选汉字、按键主字符 |
| **次级文字 (Text Secondary)**| `#aaaaaa` / `#999999`| 中灰 | 时间戳、字数统计、副字母 |
| **危险操作 (Destructive)** | `#ff453a` | 醒目暗红 | 删除键文字、清空提醒 |

## 四、触觉震动反馈最佳实践

物理按键敲击时，人脑会通过按键行程感知“操作已生效”。但在纯平玻璃小屏幕上，缺失行程感会导致用户产生**疑虑性多次连击**。

```
[ 用户手指轻触屏幕 ]
         │
         ▼ (onclick 事件立即触发)
[ vibrator.vibrate({ mode: 'short' }) ] ──► [ 线性马达清脆微震动 ]
         │
         ▼
[ 同步执行业务逻辑 / 刷新 UI ]
```

- **高频操作（打字、光标移动）**：一律使用 `short` 微震动。
- **边界事件（翻到最后一页、退格到首字）**：不震动或震动两次予以区分。
- **错误捕获包裹**：手环系统在电量极低（如低于 10%）或节电模式下可能暂时禁用震动马达，调用处必须使用 `try-catch` 包裹，防止未捕获异常引发崩溃。

## 五、表盘 (Watchface) 与快应用的互联机制

### 1. 表盘开发特性：
- **静态表盘**：通过小米官方表盘工具（Easyface 等）配置 XML 和切图，功耗极低，由系统 Surface 直接渲染。
- **AOD (Always-On Display) 息屏微光铁律**：
  - AOD 模式下，**像素发光率（OPR）必须低于 10%~15%**。
  - 严禁在大面积区域显示非黑色背景，禁止复杂连续动画，避免烧屏和电池迅速耗尽。

### 2. 表盘唤起快应用：
在表盘画布上圈定“点击热区（Hotspot）”，配置跳转动作直接呼起对应的快应用包名：
```json
{
  "action": "jump_app",
  "target": "com.xiaomi.band.notepad"
}
```
用户在表盘上轻点日期/便签小部件，即可瞬间跳转进入独立快应用，体验如同原生系统组件无缝衔接。
