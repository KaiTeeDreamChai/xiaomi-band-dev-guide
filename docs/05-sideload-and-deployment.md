# 05. 蓝牙侧载、签名体系与真机部署指南 (AstroBox & Tools)

> 本章介绍如何将编译生成的 `.rpk` 快应用安装包通过蓝牙无线推送到小米手环真机上，详解 AuthKey 获取、蓝牙链路冲突排查与常见部署故障自查表。

---

## 一、主流第三方蓝牙侧载工具简介

由于小米官方未对个人开发者完全开放免审核真机无线推包入口，目前社区主要依托成熟的蓝牙通信协议工具进行应用侧载：

1. **AstroBox（首选推荐）**：
   - 官方网站：[https://astrobox.online/](https://astrobox.online/)
   - 跨平台支持（Windows / macOS / Linux / Android / iOS / Web 网页端），界面现代，支持一键连接手环并推送表盘与 RPK 快应用。
2. **表盘自定义工具（Watchface Customizer）**：
   - 国内米坛社区老牌安卓端工具，具备丰富的手环固件及文件传输协议支持，支持通过文件替换与蓝牙直连推送。
3. **Notify for Xiaomi**：
   - 海外知名的第三方穿戴管理 App，侧重健康通知与底层蓝牙抓包，支持手动刷入更新文件与固件包。

## 二、关键前提：获取手环的 AuthKey 与切断官方 App 占用

小米手环 9 / 9 Pro 相比早期手环增强了低功耗蓝牙（BLE）安全通信协议，手环在建立数据传输通道时必须通过 32 位 `AuthKey`（设备绑定密钥）校验。

### 1. 获取 AuthKey 的主流方式（以 AstroBox 为例）
1. 确保手环已在手机端官方“小米运动健康 (Mi Fitness)”中完成初次配对与正常同步。
2. 打开 [AstroBox 官网](https://astrobox.online/)（推荐使用支持 WebBluetooth 的 Chrome/Edge 浏览器）或下载 AstroBox 客户端。
3. 在工具设置中选择 **“小米账号登录”**，授权登录绑定了该手环的小米云账号。
4. AstroBox 将自动从小米服务器拉取当前账号绑定的设备列表并解析出该手环对应的 **32 位 AuthKey**。
5. 工具会自动将密钥写入当前会话，后续可直接一键发起蓝牙配对。

> [!CAUTION]
> **GATT 133 冲突铁律：切断官方 App 蓝牙占用！**
> 小米手环的 BLE 协议在同一时刻**只能与一个主机进程建立活跃通信通道**。
> 在使用 AstroBox 扫描或连接手环前，**必须在手机系统设置中将“小米运动健康”强制停止（Force Stop）**或临时关闭其蓝牙权限。否则官方 App 会在后台频繁争抢 GATT 连接，导致 AstroBox 报 `GATT Error 133` 或在分包推送时中断在 0%。

## 三、真机安装部署全流程

```
[ 本地构建 (npm run build) ] ──► 生成 debug.rpk (例如 35KB)
                                        │
                                        ▼ (文件传入手机或电脑)
                         [ 强制停止后台“小米运动健康” ]
                                        │
                                        ▼
                         [ 打开 AstroBox / 侧载工具 ]
                                        │
                                        ▼ (基于 AuthKey 握手连接手环)
                         [ 选择目标 RPK 文件并点击推送 ]
                                        │
                                        ▼ (蓝牙分包传输进度 0% ~ 100%)
                         [ 手环系统解包校验并注册入口 ]
                                        │
                                        ▼
                         [ 手环应用列表中出现全新应用！ ]
```

### 分步操作指南：
1. **生成目标安装包**：
   在终端执行：
   ```bash
   npm run build
   ```
   在 `dist/` 目录下生成 `com.xiaomi.band.<appname>.debug.<version>.rpk`。
   > **注意**：侧载调试必须使用 `debug` 包，手环固件禁止未授权的自签名 `release` 包。

2. **切断官方连接并启动侧载工具**：
   - 手机端强制停止“小米运动健康”。
   - 打开 AstroBox（手机客户端或电脑网页端），确保蓝牙开启。

3. **搜索并连接手环**：
   - 点击“搜索设备”，选中你的“小米手环 9 / 9 Pro”。
   - 若已配置好 AuthKey，手环会震动提示或直接连接成功。

4. **选择文件并推送**：
   - 在 AstroBox 的“应用安装”或“快应用”模块中，点击“选择本地文件”，选取上述生成的 `debug.rpk`。
   - 点击“开始安装”，观察手环蓝牙分包传输进度条（35KB 文件通常只需 3~5 秒）。

5. **在手环上验证**：
   - 传输完成后，手环屏幕提示“安装成功”。
   - 点亮手环屏幕，上滑打开应用列表，即可找到刚安装的快应用图标，轻点即可立即启动！

## 四、真机部署常见故障自查表 (Troubleshooting)

遇到推包失败、安装后闪退或无反应时，请按顺序排查以下项：

| 故障现象 | 潜在根本原因 | 排查与修复方案 |
| :--- | :--- | :--- |
| **AstroBox 搜不到手环或连接失败** | 1. 官方“小米运动健康”正在后台保持连接<br>2. 蓝牙广播处于休眠状态 | 1. 强制杀死官方 App 进程。<br>2. 在手环设置中开启“重新连接”或临时开关一次手环飞行模式。 |
| **提示 `AuthKey invalid` 或认证失败** | 手环在官方 App 重新解绑再绑定过，云端重置了通讯密钥 | 在 AstroBox 中重新登录小米账号，重新同步最新的设备 AuthKey。 |
| **传输进度卡在 0% 或中途报 GATT 133** | 手机官方 App 尝试在后台重新唤醒并争夺蓝牙通道 | 彻底关闭官方 App 权限，重启手机蓝牙后重连 AstroBox。 |
| **AstroBox 提示“证书校验失败 / 非法安装包”** | 误刷了 `npm run release` 产出的正式包，手环未配置对应私钥信任链 | **必须换用 `npm run build` 生成的 `debug.rpk` 安装包**。系统固件为开发者豁免了 debug 证书校验。 |
| **安装后点击应用图标直接闪退 / 黑屏** | 1. 存在未被 try-catch 拦截的顶层 JS 语法报错<br>2. 代码中误调用了浏览器特有 API（如 `window`、`document`）<br>3. `manifest.json` 配置缺失 | 1. 检查 `src/manifest.json` 中 `deviceTypeList` 是否包含 `"watch"`。<br>2. 搜索并移除代码中的一切 Web 全局对象。<br>3. 在入口 `onInit` 首行加全链路 try-catch，并配合 UI 调试看板输出错误信息。 |
| **打开应用屏幕全黑，没有任何响应** | 1. 未设置根容器物理宽高<br>2. 纯文本裸露在 `<div>` 外未包裹在 `<text>` 中 | 1. 检查根节点是否有显式的 `width: 336px; height: 480px;`（9 Pro）或 `width: 192px; height: 490px;`（9 标准版）。<br>2. 确保所有文字都包裹在 `<text>` 中。 |
| **提示手环存储空间不足 (Out of Storage)** | 历史 RPK 残留过多，或手环用户存储分区已满 | 在手环“设置 -> 应用管理”或通过 AstroBox 卸载无用的旧应用，单只手环建议常驻第三方应用不超过 3~5 个。 |
| **安装成功但覆盖更新后原先数据丢失** | `manifest.json` 中的 `package` 标识串被修改 | 手环以 `package` 字符串作为数据沙盒的隔离唯一 Key，版本升级必须保持 `package` 完全一致。 |
