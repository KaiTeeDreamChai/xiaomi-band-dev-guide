# 05. 蓝牙侧载、签名体系与真机部署指南 (AstroBox & Tools)

> 本章介绍如何将编译生成的 `.rpk` 快应用安装包通过蓝牙无线推送到小米手环真机上，并提供常见部署故障自查表。

---

## 一、主流第三方蓝牙侧载工具简介

由于小米官方未对个人开发者完全开放免审核真机无线推包入口，目前社区主要依托成熟的蓝牙通信协议工具进行应用侧载：

1. **AstroBox（首选推荐）**：
   - 跨平台支持（Android / iOS / 网页版），界面现代，支持一键连接手环并推送表盘与 RPK 快应用。
2. **表盘自定义工具（Watchface Customizer）**：
   - 国内社区老牌工具，具备丰富的手环固件及文件传输协议支持。
3. **Notify for Xiaomi**：
   - 侧重健康通知与底层蓝牙抓包，支持手动刷入更新文件。

## 二、真机安装部署全流程

```
[ 本地构建 (npm run build) ] ──► 生成 debug.rpk (例如 36KB)
                                        │
                                        ▼ (文件传入手机或电脑)
                         [ 打开 AstroBox / 侧载工具 ]
                                        │
                                        ▼ (开启蓝牙配对连接手环)
                         [ 选择目标 RPK 文件并点击推送 ]
                                        │
                                        ▼ (蓝牙分包传输进度 0% ~ 100%)
                         [ 手环系统解包校验并注册入口 ]
                                        │
                                        ▼
                         [ 手环应用列表中出现全新应用！ ]
```

### 分步操作指南：
1. **生成目标安装包**：
   在终端执行：
   ```bash
   npm run build
   ```
   在 `dist/` 目录下生成 `com.xiaomi.band.<appname>.debug.<version>.rpk`。
2. **启动侧载工具**：
   打开手机端 AstroBox，确保手机蓝牙开启且手环已处于连接状态。
3. **选择文件**：
   在 AstroBox 的“应用安装”或“快应用”模块中，选取上述生成的 `.rpk` 文件。
4. **无线传输**：
   点击“安装”，等待传输完成（36KB 文件通常只需 3~5 秒）。
5. **在手环上验证**：
   点亮手环屏幕，上滑打开应用列表，即可找到刚安装的快应用，点击即可立即启动。

## 三、真机部署常见故障自查表 (Troubleshooting)

遇到推包失败、安装后闪退或无反应时，请按顺序排查以下项：

| 故障现象 | 潜在根本原因 | 排查与修复方案 |
| :--- | :--- | :--- |
| **AstroBox 提示“证书校验失败 / 非法安装包”** | 使用了 `release` 签名包，手环固件没有对应私钥的信任证书 | **换用 `npm run build` 生成的 `debug.rpk` 安装包**。开发签名无需官方信任链。 |
| **传输进度卡在 0% 或中断** | 蓝牙连接不稳定，或正在同步小米运动健康数据 | 暂时关闭手机端小米运动健康 App，在 AstroBox 中重新断开并重连蓝牙。 |
| **安装后点击应用图标直接闪退** | 1. 存在未被 try-catch 拦截的顶层 JS 语法报错<br>2. 调用了不存在的 Web API（如 `window`）<br>3. `manifest.json` 配置严重缺失 | 1. 检查 `src/manifest.json` 中 `deviceTypeList` 是否包含 `"watch"`。<br>2. 检查代码中是否有浏览器特有对象。<br>3. 在入口 `onInit` 首行加 try-catch。 |
| **打开应用屏幕全黑，没有任何响应** | 1. 未设置容器尺寸<br>2. 纯文本裸露在 `<div>` 外未用 `<text>` 包裹 | 1. 检查根节点是否有 `width: 336px; height: 480px;`。<br>2. 确保所有文字都包裹在 `<text>` 中。 |
| **安装成功但覆盖更新后数据丢失** | `manifest.json` 中的 `package` 包名发生了变动 | 手环系统以 `package` 字符串作为数据沙盒的隔离唯一 Key，升级必须保持包名完全一致。 |
